# 着色器代码长什么样

一份 GLSL ES 阅读课。OpenGL ES 用来写着色器的语言不是 C，也不是 JavaScript：它是两段（或更多段）类 C 的文本，在 GPU 上分别为每个顶点和每个片元运行。

这个页面把常用写法和使用场景拆成可以切换的课文。每一则都给出：

- 正在 GPU 上跑的画面
- 完整的顶点着色器、片段着色器
- 对应的 WebGL 调用
- 点某一行时，旁边的说明

范围是 GLSL ES 1.00 和 3.00，也就是 OpenGL ES 2.0 / 3.0，以及浏览器里的 WebGL 1 / 2。计算着色器属于 ES 3.1，页面里只放源码，不编译。

## 本地运行

```bash
npm install
npm run dev
```

开发服务器打印出本地地址后，用浏览器打开。从「一份最小的着色器」读起。左右方向键可以切换课文。距离场那一则可以拖动，圆会跟着指针走。

## 课文在讲什么

1. 一份源码的骨架：版本号、精度、`in` / `out`、`main`、`gl_Position`
2. `main` 会为每个顶点、每个片元各跑一遍
3. 类型、精度限定符、不允许的隐式转换
4. 分量重组、内置函数、函数 / 结构体 / 数组 / `switch` / 宏
5. 矩阵按列书写
6. 渲染管线：绘制调用、裁剪与透视除法、光栅化、剔除、深度、混合、模板
7. 顶点属性、uniform、`flat` 插值、std140 统一缓冲
8. `gl_FragCoord`、点精灵、实例化
9. 距离场、`fwidth`、图案、噪声、纹理
10. MVP、Blinn-Phong、顶点位移、`discard` 与 alpha
11. ES 1.00 和 3.00 的关键字对照，以及 ES 3.1 的计算着色器
